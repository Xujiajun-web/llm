2028 届硕士，脑电方向。用十二周从零走一遍大模型全链路：
手写 GPT、预训练、SFT、偏好对齐、RAG 与智能体、多模态接入、评测体系。

## 这个仓库是什么

一份按天推进的学习与实现记录。每天的代码、日志、笔记都在这里，
不是为了展示成果，是为了留下每一步的取舍依据。

## 目录

- `code/` 按天编号的脚本
- `logs/` 当日日志：做了什么、跑出什么数字、卡在哪
- `notes/` 概念笔记与决策记录
- `reports/` 评测报告、技术报告、周期小结

## 怎么跑

环境：Python 3.11，CUDA 版 PyTorch（cu128），按小时租的 24G 单卡，
详见 `notes/env.md`。
